# اختبارات AI AYFAM

لم يكن للمشروع اختبار آلي قبل التحديثات الأخيرة. هذه المجموعة (146
اختباراً) تغطي تحديثي "البحث والتحليل" ثم "الذكاء المحلي v4 + الواجهة"
تحديداً — وليست تغطية شاملة لكل المشروع.

## التشغيل

```bash
cd tests
python3 test_web_new.py            # 25 — بحث ويب/CVE/OSV/ExploitDB/IP (بيانات وهمية)
python3 test_intelligence_new.py   # 21 — ربط النتائج + المقارنة التاريخية
python3 test_system_new.py         #  6 — اكتشاف الحزم القابلة للترقية
python3 test_nlp_new.py            # 14 — التوجيه للأوامر (v3 + v4)
python3 test_relevance_engine.py   # 28 — محرك TF-IDF/TextRank/خريطة المفاهيم واكتشاف الفهرس القديم
python3 test_integration.py        # 21 — تشغيل الوكيل الحقيقي كاملاً محلياً (v3)
python3 test_cve_enrichment.py     #  4 — مسار نجاح ربط CVE (بمحاكاة اتصال)
python3 test_v4_integration.py     # 20 — تعلّم كتب حقيقية + بناء الفهرس + كل أوامر v4
python3 test_terminal_ui.py        #  8 — كل دوال الواجهة (rich + no_color) بلا كراش
python3 test_gui_app.py             #  9 — إدخال GUI، إشارات الخيط، ومخرجات المهام
```

اختبار GUI يحتاج مكتبات Qt النظامية؛ يتجاوز نفسه برسالة واضحة إذا كانت غير متاحة.

كل الاختبارات تعمل بلا إنترنت فعلي (تُحاكي استجابات الشبكة بدلاً من
استدعائها)، ما عدا أنها تُنفِّذ فعلياً أوامر نظام حقيقية (مثل `apt list
--upgradable`) في اختبار التكامل، وتبني فهرس TF-IDF حقيقياً على كتب
اصطناعية واقعية — آمنة تماماً على أي جهاز (قراءة فقط، بيانات مؤقتة معزولة
عن ~/.ayfam الحقيقي).

## ما لا تغطيه هذه المجموعة

- الاتصال الفعلي بـ NVD/CISA/DuckDuckGo/OSV.dev/ipapi.co/ip-api.com —
  هذه اختُبِرت منطقياً عبر بيانات وهمية مطابقة للتنسيق الرسمي، وليس
  عبر طلب شبكي حقيقي فعلي وقت الكتابة.
- الأداء الفعلي على مكتبة حقيقية من مئات الكتب — الاختبارات تستخدم كتباً
  اصطناعية صغيرة (كافية للتحقق من صحة المنطق)، وليس قياس أداء حقيقي على
  200 كتاب × 700 صفحة.
- بقية أجزاء المشروع السابقة على هذه التحديثات (USB، التعلّم القديم بلا
  TF-IDF...) — راجع ملفات UPGRADE الأخرى لسياقها.
