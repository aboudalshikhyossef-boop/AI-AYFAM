## الإصلاحات المنفذة

### 1. إصلاح انهيار واجهة Qt

كان callback إشارة `destroyed` في `HoverController` يستدعي خصائص قد تكون أزيلت أثناء إغلاق Qt، مما أدى إلى:

```text
AttributeError: 'HoverController' object has no attribute 'overlays'
Aborted (exit code 134)
```

تم جعل التنظيف idempotent وآمناً أثناء إغلاق التطبيق باستخدام `getattr`، مع الحفاظ على السلوك الطبيعي أثناء التشغيل.

### 2. تحميل `.env`

تم تفعيل تحميل ملف `.env` الموجود بجانب المشروع عبر `python-dotenv`، مع أولوية لمتغيرات البيئة الممررة من النظام وعدم الكتابة فوقها.

### 3. تحسين فحص التبعيات

تمت إضافة التحقق من:

- `python-dotenv`.
- `cryptography`.
- `yara-python`.

كما تم تصحيح `feature_flags` حتى لا يحول خيار `--scan` المنطقي إلى اسم ميزة غير صالح.

### 4. تشديد API المحلي

- إزالة CORS المفتوح بعلامة `*`.
- السماح افتراضياً فقط بـ `http://127.0.0.1:3000` و`http://localhost:3000`.
- دعم التوسعة الصريحة عبر `AYFAM_ALLOWED_ORIGINS`.
- رفض طلبات GET/POST/OPTIONS ذات Origin غير مسموح.
- التحقق من هدف الفحص عبر `validate_scan_target` قبل تمريره إلى ماسح المنافذ.
- استمرار رفض الأطوال غير الصالحة وJSON غير الكائن كما كان.

### 5. تثبيت الأدوات Python

تم إنشاء `.venv` معزولة داخل المشروع وتثبيت كل متطلبات `requirements.txt` فيها، بما في ذلك PyQt6 وpytest وscikit-learn وgoogle-genai وyara-python.

## التبعيات النظامية الناقصة في بيئة الفحص

لا تمنع هذه الأدوات تشغيل الوظائف الأساسية، لكنها تحد بعض الميزات، ويطالب بها `main.py --check` مباشرة بأوامر تثبيت واضحة:

```bash
sudo apt install nmap
sudo apt install usbutils
sudo apt install lynis
sudo apt install chkrootkit
```

كما أن بعض مكتبات X11 الاختيارية لواجهة Qt غير موجودة في بيئة Sandbox:

```bash
sudo apt install libxcb-cursor0 libxcb-icccm4 libxcb-image0 \
  libxcb-keysyms1 libxcb-render-util0
```

## ملاحظات متبقية للخطوات التالية

1. بعض بيانات لوحة Angular الابتدائية مصممة كبيانات عرض قبل أول فحص، بينما مسار الفحص نفسه حقيقي ويستبدل النتائج فقط بعد استجابة `/api/scan` ناجحة.

3. يفضل إضافة اختبارات pytest رسمية لـ API handler نفسه واختبارات واجهة Angular لـ success/error/timeout، ثم إعداد CI موحد.
4. لا يتم نشر أي تغيير إلى GitHub تلقائياً ضمن هذه المرحلة؛ التغييرات موجودة محلياً وقابلة للمراجعة قبل commit أو push.
